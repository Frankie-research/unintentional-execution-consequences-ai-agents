# Public Publication Security Review

Before any upload, search the complete release folder for:

- API keys
- access tokens
- passwords
- SMTP credentials
- Telegram bot tokens
- private email addresses other than the intended research contact
- Windows usernames or private paths that should not be public
- NAS paths or private network addresses
- database files
- private ChatGPT URLs
- browser/session data
- internal Hermes configuration files
- `.env` files
- Docker credentials
- SSH keys
- cloud credentials

The public report should describe security architecture and lessons without publishing credentials or operational secrets.

The report's discussion of advanced agent behaviours should be labelled as observed evidence, analytical scenario, or external research evidence as appropriate. Do not convert a hypothetical scenario into an empirical claim during platform editing.
